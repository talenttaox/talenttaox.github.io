# 第十四章 心理障碍

## 一、背景：如何理解心理障碍

心理障碍涉及思维、情绪、行为或相关功能的扰乱，并可能造成显著痛苦和功能受损。异常心理学研究其特点、原因与过程。

历史上曾使用痛苦、适应不良、非理性、不可预测、统计罕见、令他人不适、违反规范等判断标准。**辨析：**罕见、与众不同或令旁观者不适，不能单独证明障碍；须结合背景、文化和功能。诊断标签还可能受社会权力与偏见影响。

分类帮助沟通、研究及治疗规划。**病因学**研究促进障碍形成和发展的因素。生物、心理动力、行为、认知及社会文化模型各关注不同环节。

**素质—应激模型**强调易感性与压力及保护因素相互作用。具有易感性不等于必然发病，单一生物指标也不能解释全部心理障碍。

## 二、焦虑、强迫与创伤相关问题

| 概念 | 核心特点 |
| --- | --- |
| 广泛性焦虑障碍 | 持续、过度且难以控制的担心，伴紧张等表现 |
| 惊恐发作 | 突然强烈恐惧或不适，伴心悸等反应 |
| 惊恐障碍 | 反复意外发作，并持续担心或改变行为 |
| 特定恐怖症 | 对特定对象或情境强烈恐惧与回避 |
| 广场恐怖症 | 害怕在难以逃离或难以获得帮助的情境中出事 |
| 强迫观念 | 反复侵入、引起不适的想法、冲动或意象 |
| 强迫行为 | 为减轻不适或避免担忧结果而实施的重复行为或心理活动 |
| 创伤后应激障碍PTSD | 创伤之后出现再体验、回避等持续症状及功能影响 |

**分类辨析：**DSM-5框架将强迫及相关障碍、创伤及应激相关障碍分别设为类别。[美国精神医学学会期刊：DSM-5分类变动](https://psychiatryonline.org/doi/pdf/10.1176/appi.ajp.2014.14010003?download=true)。

焦虑可以从遗传、生理准备、条件作用及危险评价等角度解释。**焦虑敏感性**是担心身体唤醒本身会带来严重后果的倾向。

**例：**回避暂时减少焦虑，可能通过负强化维持回避；灾难化解读心跳，又可能加剧惊恐体验。

## 三、抑郁与双相

抑郁与双相在历史分类中常被归入“心境障碍”这一总类别。抑郁涉及持续低落或兴趣下降，也可能有睡眠、食欲、精力、注意及自我评价变化。偶尔不开心与持续、影响功能的症状模式需区分。

**躁狂**涉及异常升高或易激惹的心境，以及精力、活动等变化。**双相障碍**涉及躁狂或轻躁狂等发作模式，有时伴抑郁发作。

**辨析：**并非所有双相病例都呈现严格的抑郁—躁狂交替，双相Ⅰ型的核心涉及躁狂发作，不能把“躁狂之后几乎必然立即抑郁”当作规则。[NIMH：双相障碍](https://www.nimh.nih.gov/health/publications/bipolar-disorder)。

相关心理解释包括强化减少、消极思维、习得性无助及归因风格。

- **抑郁认知三联征：**对自己、当前世界或经验、未来的消极认识。
- **习得性无助：**不可控经历影响后来行动、认知和情绪。
- **反刍：**反复停留在痛苦、原因和后果上。

**辨析：**不能把抑郁或躁狂简单归结为某两种递质“太低或太高”，多种机制共同参与。无望、孤立等因素与自杀风险有关，群体关联不能确定个人结局。

## 四、躯体症状及分离

| 概念 | 入门解释 |
| --- | --- |
| 躯体症状障碍 | 身体症状与过度相关的想法、焦虑或行为造成显著困扰 |
| 疾病焦虑障碍 | 对患病或可能患病高度担心，躯体症状可能较轻 |
| 转换障碍／功能性神经症状障碍 | 出现运动或感觉功能症状，其特点与已知疾病模式不一致 |
| 分离 | 意识、记忆、身份等正常整合受到扰乱 |
| 分离性遗忘 | 对重要个人经历出现超出通常遗忘的记忆缺失 |
| 分离性身份障碍 | 身份状态及记忆整合等方面的扰乱 |

**辨析：**躯体症状障碍不要求症状必须“查不出疾病原因”。真实躯体疾病可以同时存在，不能据此认定症状是装出来的。[美国精神医学学会：躯体症状障碍](https://www.psychiatry.org/patients-families/somatic-symptom-disorder/what-is-somatic-symptom-disorder)。

分离性漫游涉及个人经历记忆丧失以及离开惯常环境等表现。分离概念涉及身份和记忆，不能与精神分裂症混淆。

## 五、精神分裂症谱系

**阳性症状**指出现或增强的异常体验，如幻觉、妄想及思维、行为紊乱。**阴性症状**指原有功能减少，如情感表达减少、动机减弱。这里“阳性／阴性”不是好坏评价。

**幻觉**是没有相应外界刺激的知觉体验。**妄想**是与现实证据明显不符、难以被纠正的坚定信念。精神分裂症不是“一个人有多个性格”。

相关解释涉及遗传风险、脑功能及环境应激。群体脑影像差异不能直接拿来给某个人作诊断，相关生活因素也不意味着每个经历者都会患病。

## 六、人格及神经发育问题

**人格障碍**涉及长期、僵化、与环境适应困难的体验和行为模式。边缘型常涉及不稳定的关系、情绪及自我体验，反社会型涉及持续侵犯他人权益、缺乏责任等特点。不能凭一场争执或一次违规给人贴标签。

**ADHD**涉及持续的注意缺陷和／或多动冲动，影响多个情境的功能。**辨析：**不要求注意缺陷与多动冲动两类症状必须同时明显存在，可表现为不同类型。[NIMH：ADHD概念与类型](https://www.nimh.nih.gov/health/publications/adhd-what-you-need-to-know)。

**孤独症谱系**涉及社会沟通特点及限制、重复行为等，表现与支持需求具有多样性。**辨析：**个体理解他人心理状态的能力存在差异，不能用“完全不能理解”等绝对表述概括所有人。[NIMH：孤独症谱系](https://www.nimh.nih.gov/health/topics/autism-spectrum-disorders-asd)。

## 七、污名与自测

**污名**是与标签相连的贬低态度，**自我污名**是内化这些负面评价。尊重个体、关注功能与需要，有助于避免用诊断替代完整的人。

患病率随时间、地区、样本与统计口径而变化，不能把某项研究的比例视为全球通用数值。

1. “罕见”能否单独证明障碍？**答案：**不能。
2. 阳性症状与阴性症状各指什么？**答案：**异常体验增加与原有功能减少。
3. 为什么分离性身份障碍不是精神分裂症？**要点：**核心概念分别是身份记忆整合与精神病性症状等。
