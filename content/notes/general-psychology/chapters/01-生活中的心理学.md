# 第一章 生活中的心理学

## 一、背景与本章主线

心理学研究个体的行为与心智过程。行为包括人和其他动物可观察的活动，心智过程包括思考、计划、记忆、创造和做梦。心理学采用科学方法，通过可检验的问题、系统收集的数据和公开的方法形成解释。

心理问题早已存在于哲学讨论中。经验主义强调知识来自经验，以亚里士多德、洛克为代表；先天论强调人与生俱来的心理结构对经验产生影响，以柏拉图、康德为代表。现代心理学的重要转变，是把这些问题放到实验与观察中检验。

“天性与教养”并非只能二选一。研究者往往需要说明遗传条件、个人经验和社会环境如何共同影响行为。

## 二、心理学的四个目标

| 目标 | 要回答的问题 | 以吸烟为例 |
| --- | --- | --- |
| 描述 | 发生了什么，发生在什么条件下？ | 记录吸烟频率、场合和同伴情况 |
| 解释 | 为什么会发生？ | 考察个人倾向、同伴压力和强化经历 |
| 预测 | 在指定条件下可能发生什么？ | 提出可检验的复吸风险预测 |
| 控制或干预 | 怎样改变相关条件和行为？ | 设计并检验减少吸烟的干预 |

描述需要尽量减少观察者的偏见与期望。解释应兼顾内部因素和外部因素。预测必须足够明确，允许证据推翻它。干预的意义在于改善生活质量。

不同分析水平关注不同的问题。例如，社会层面可以研究偏见，个体层面可以研究交通灯反应时，生物层面可以研究记忆与脑活动。它们提供互补的信息。

## 三、现代心理学的历史根基

- **冯特：**建立正式实验心理学实验室，代表心理学走向实验研究。
- **铁钦纳与结构主义：**借助内省分析心理经验的构成，关注心理结构。其局限包括把复杂经验过度拆解为元素。
- **詹姆士与机能主义：**重视心理和行为的功能，追问它们如何帮助个体适应环境。
- **格式塔心理学：**强调有组织的整体，惠特海默是重要代表。
- **杜威：**强调教育中的“做中学”，把功能与实际活动联系起来。
- **霍尔：**与美国心理学协会的发展有关。

女性先驱也为心理学发展作出重要贡献：卡尔金斯研究记忆并成为美国心理学协会首位女主席；沃什布恩成为首位获得心理学博士学位的女性；伍利、霍林沃斯研究智力及性别差异。理解这部分时，也应注意教育机会与社会偏见对学科发展的影响。

## 四、七种心理学观点

| 观点 | 解释重点 | 代表与关键词 |
| --- | --- | --- |
| 心理动力学 | 无意识动机、内在冲突、早期经验 | 弗洛伊德 |
| 行为主义 | 环境刺激、反应及其后果 | 华生、斯金纳 |
| 人本主义 | 选择、个人体验、成长潜能 | 罗杰斯、马斯洛、自我实现 |
| 认知 | 注意、思维、记忆、语言等加工过程 | 乔姆斯基、皮亚杰 |
| 生物学 | 基因、脑、神经和内分泌机制 | 行为神经科学、认知神经科学 |
| 进化 | 心理机制可能具有的适应功能 | 自然选择、适应性问题 |
| 社会文化 | 社会环境及跨文化异同 | 文化普遍性与文化特异性 |

可以用同一行为比较观点。例如，考试焦虑可从强化经历、威胁性想法、生理唤醒及评价文化分别解释。各观点的解释仍须接受证据检验，不能只凭“听起来合理”判断。

## 五、重点名词

| 名词 | 解释 |
| --- | --- |
| 心理学 | 对个体行为和心智过程的科学研究 |
| 行为数据 | 关于行为以及行为发生条件的观察记录 |
| 客观性 | 用明确程序和证据降低个人偏见对结论的影响 |
| 内省法 | 对自身心理经验进行观察和报告的方法 |
| 结构主义 | 研究心理经验构成及结构的历史学派 |
| 机能主义 | 研究心理与行为的功能和适应意义的历史学派 |
| 自我实现 | 努力发展并实现个人潜能的过程 |

## 六、心理学家做什么

认知心理学研究记忆、语言等基础过程；社会心理学研究社会力量对态度和行为的影响；工业与组织心理学关注工作环境；教育心理学关注教育情境中的学习和适应；临床心理学将评估和干预用于改善个体生活。基础研究与应用研究可以相互促进。

## 七、复习自测

1. 心理学的“科学”体现在哪些环节？**答题要点：**系统观察、客观记录、可检验解释、证据检验。
2. 结构主义与机能主义的侧重点有何不同？**答题要点：**经验由什么组成，与它有什么功能。
3. 用三种不同观点解释拖延。**答题要点：**可分别分析行为后果、认知评价及社会情境。
