# 第二章 心理学的研究方法

## 一、背景：心理学如何把问题变成证据

研究通常经历七个环节：提出观察或问题，形成理论与假设，设计研究，分析数据与得出结论，报告发现，识别开放问题，再次研究。

**理论**是一组用于解释现象的有组织概念。**假设**是从理论或已有证据产生的、可以检验的具体陈述。例如，研究情侣语言风格与关系稳定性时可以发现：语言风格匹配度与后续关系维持有关，但仅凭这种关联，尚不能判断因果方向。

## 二、变量与操作性定义

| 名词 | 解释 | 例子 |
| --- | --- | --- |
| 变量 | 能取不同数值或类别的属性 | 反应时、睡眠时长 |
| 自变量 | 实验者操纵的因素 | 是否受到手机通知干扰 |
| 因变量 | 实验者测量的结果 | 阅读理解正确率 |
| 操作性定义 | 用具体操作或测量程序界定概念 | 用一套明确任务的正确率表示理解表现 |
| 混淆变量 | 与自变量变化相伴、也可能影响结果的因素 | 两组任务难度不同 |
| 观察者偏差 | 观察者动机或预期导致记录、解释偏差 | 更容易注意到符合预期的行为 |

**标准化**要求收集数据时采用一致程序。操作性定义使抽象概念可测量，但一个指标未必覆盖概念的全部意义。

## 三、实验控制与研究设计

实验法通过操纵自变量并控制其他条件，检验对因变量的影响。

- **期望效应：**研究者以微妙方式传达预期，改变参与者的反应。
- **安慰剂效应：**参与者对处理的期待等因素引起变化。**辨析：**安慰剂条件一般使用不含目标有效成分的模拟处理，不等同于完全不处理。
- **双盲控制：**参与者及接触、评估他们的研究人员不知道处理分组，减少双方预期的影响。
- **被试间设计：**不同参与者接受不同条件。随机分配有助于平衡各组原有差异。
- **被试内设计：**同一参与者接受多个条件。可减少个体差异影响，但需注意练习、疲劳和条件顺序的影响。

**随机取样与随机分配不能混淆：**前者决定从总体中选谁，主要影响代表性；后者决定参与者进入哪组，主要服务于组间可比性。实验的优势是因果推断能力，局限包括情境人为化、参与者揣测研究意图，以及伦理限制。

## 四、相关法与测量

相关法研究变量间关联。相关系数 `r` 的范围为 `-1` 到 `+1`，符号表示方向，绝对值表示线性关联强度。`r=0` 不保证完全没有任何关系。

相关不能单独证明因果。睡眠与成绩正相关，可以由睡眠影响学习、学习压力影响睡眠，或课程难度同时影响二者来解释。

| 测量方式 | 适合收集什么 | 主要局限 |
| --- | --- | --- |
| 自我报告 | 主观体验、难以直接观察的经历 | 记忆误差、社会期望、问题理解差异 |
| 行为观察 | 可记录的活动与反应 | 观察者偏差、被观察反应 |
| 自然观察 | 自然情境中的行为 | 控制较少，难以单独建立因果 |
| 个案研究 | 特殊个体或小群体的深入资料 | 推广范围有限 |

**信度**是测量的一致性或可靠性。**效度**是测量和解释是否支持目标用途。稳定地测错东西也可以有高信度，因此高信度不保证高效度。

## 五、研究伦理

知情同意包括说明程序、风险与利益，保护隐私，并允许参与者退出。研究者须评估风险与收益。使用欺骗需有充分理由、没有同等有效替代方式，并进行事后解释，给予适当撤回数据的机会。

动物研究的 **3R原则**：减少数量、采用替代方式、优化程序以降低疼痛和不适。

## 六、统计学要点

| 术语 | 含义 |
| --- | --- |
| 频次分布 | 各分数或类别出现多少次 |
| 众数 | 出现次数最多的值 |
| 中位数／中数 | 数据排序后的中间位置值 |
| 平均数 | 数值总和除以数量 |
| 全距 | 最大值减最小值 |
| 标准差 | 描述数据围绕均值的分散程度 |
| 描述统计 | 概括手头样本的特点 |
| 推论统计 | 利用样本及统计模型判断总体、差异或关联 |
| t检验 | 在相应假设下检验均值差异的方法 |

**统计显著性的辨析：**p值是在零假设和模型假设成立时，出现当前或更极端数据的概率。它不是“零假设为真的概率”，也不能证明结果必然真实。统计显著与实际效果大小是不同问题。

参考：[美国统计协会：p值与统计显著性声明](https://www.amstat.org/asa/files/pdfs/p-valuestatement.pdf)。

## 七、批判性阅读与自测

阅读研究时检查概念如何定义、样本来自哪里、与什么比较、有无其他解释、是否报告变异和效果。主动寻找可能反驳结论的证据。

1. 高信度是否保证高效度？**答案：**不保证。
2. 随机取样与随机分配各解决什么问题？**答案：**代表性与组间可比性。
3. “咖啡喝得多的人成绩高”能说明咖啡提升成绩吗？**答案：**不能，需考虑反向因果和第三变量。
