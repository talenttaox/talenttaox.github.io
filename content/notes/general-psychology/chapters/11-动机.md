# 第十一章 动机

## 一、背景与动机来源

**动机**是引起、指向和维持生理及心理活动的过程。它用于解释行为为什么启动、朝向哪个目标，以及为什么在困难中持续。

| 名词 | 定义与重点 |
| --- | --- |
| 驱力 | 与生理需要相关的内部状态，如饥饿与口渴 |
| 诱因 | 能吸引或推动行为的外部刺激与结果 |
| 本能 | 与生存有关的、具有生物准备性的行为倾向 |
| 期望 | 对行为可能产生某结果的相信程度 |
| 目标价值 | 某结果对个体有多重要 |
| 归因 | 对结果产生原因的解释 |

生理状态、外部奖赏、学习经历及主观解释共同影响行为。仅用“他有某种本能”重复描述行为，容易构成循环解释，需说明机制及可检验证据。

马斯洛需要层次从生理、安全、归属与爱、尊重到自我实现。它强调成长和潜能。**辨析：**需要可以并存，现实中也可能为了价值、关系等承受生理不适，不能将层次理解为所有人必然遵守的严格阶梯。

## 二、进食：生理与心理共同作用

饥饿和停止进食涉及胃部、口腔、血液中的营养与激素信息，以及脑内多区域调节。胃部运动与饥饿有关，却不是饥饿的唯一必要条件。

传统的下丘脑双中心模型认为：外侧下丘脑LH与进食有关，腹内侧下丘脑VMH与停止进食有关。后续解释还需考虑弓状核、室旁核等结构。理解重点是分布式调节，而非把复杂进食行为完全定位到两个开关。

**特定味觉饱食感**是某种食物吃够后对它的吸引力下降，而其他味道仍可能吸引继续进食。文化、经济资源、食品选择和个人认知也影响饮食。

**BMI**的计算为 `体重kg / 身高m²`，是粗略体型指标。遗传与环境交互影响体重，限制性饮食者在压力下可能失去约束，不能只用意志力解释饮食行为。

| 进食障碍 | 核心概念 |
| --- | --- |
| 神经性厌食症 | 限制进食、显著低体重及与体重相关的恐惧或认知异常 |
| 神经性贪食症 | 反复失控性暴食，伴补偿行为 |
| 暴食障碍 | 反复暴食并感到失控，通常无规律的补偿行为 |

**辨析：**厌食症的判断需考虑年龄、发展及完整症状，不能简单以BMI18.5作为统一界线。进食障碍不能只凭外形或单一数值判断。[NIMH：进食障碍](https://www.nimh.nih.gov/health/statistics/eating-disorders)。

## 三、性行为与社会情境

动物性行为涉及激素、遗传准备和环境信号。人的性唤起与反应同时受到生理、认知、关系及文化影响。**性脚本**是从文化中学习的性情境与行为预期。实际规范与人们想象的规范之间可能存在差距。

**辨析：**性反应问题可以有生理、心理及关系因素。性互动需要尊重自主意愿和明确同意。

性取向的形成与社会对性取向的反应是不同问题。公开性取向后遭遇的敌意可能造成压力。同性恋和双性恋本身不是心理障碍。性取向的发展不能用单一、普遍的因果链概括。[美国心理学会：性取向与同性恋](https://www.apa.org/topics/lgbtq/orientation)。

## 四、成就动机与归因

**成就需要**反映努力实现目标的重要性。主题统觉测验通过模糊图片引出的故事研究相关动机。高成就需要还涉及效率和目标选择，不等于凡事投入最多时间。

归因的三个维度是内部／外部、稳定／不稳定、整体／特定。

- “我这次没掌握这一题型”是较特定的解释。
- “我永远什么都学不好”是内部、稳定、整体化解释。
- “准备方法可以调整”保留了改变未来表现的空间。

乐观解释不等于将所有失败都推卸给环境。有效归因应符合证据，并区分可改变与不可改变的因素。

## 五、工作中的动机

**公平理论**强调人会比较自己与他人的投入、产出比例，感到不公平时可能改变行为或解释。

**期望理论**用三个成分分析动力：努力是否能带来表现（期望），表现是否能带来结果（工具性），结果是否值得追求（效价）。可表示为 `动机力量 = 期望 × 工具性 × 效价`。

**例：**学生愿意准备一次考试，可能因为相信练习能提高成绩、成绩与申请机会有关，并且看重该机会。任何一个联系薄弱，都可能降低投入。

## 六、复习自测

1. 驱力与诱因分别来自哪里？**答案：**内部状态与外部结果。
2. 为什么进食不能只由胃部状态解释？**要点：**中枢信号、味觉、文化、认知和环境共同作用。
3. 期望与工具性有何不同？**答案：**努力到表现，与表现到结果。
