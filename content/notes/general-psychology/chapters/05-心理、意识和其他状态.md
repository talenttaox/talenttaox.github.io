# 第五章 心理、意识和其他状态

## 一、背景：意识指什么

意识可以指一般心理状态，也可以指对特定信息、反应和自身经验的觉知。某一时刻的**意识内容**包括正在觉察的知觉、思想、情感、意象和欲望。**自我觉知**还包括意识到“我正在经历这件事”。

| 概念 | 含义与例子 |
| --- | --- |
| 非意识过程 | 通常不进入觉知的身体调节，如血压调节 |
| 前意识记忆 | 当前未注意，但需要时可进入意识的知识或经历 |
| 未被注意的信息 | 尚未成为注意焦点的信息，仍可能获得一定加工 |
| 鸡尾酒会现象 | 专注某一谈话时，仍可能注意到其他声音中的自己的名字 |
| 心理动力学的无意识 | 弗洛伊德理论中受压抑的欲望、冲突与记忆 |
| 当代研究中的无意识加工 | 无须有意识觉察也能发生的信息加工，如部分语境消歧 |

**辨析：**不同理论对“无意识”的使用不完全相同。证明某种加工没有意识参与，并不自动证明弗洛伊德关于压抑的所有主张。

## 二、研究方法与意识功能

**出声思维报告**要求参与者边完成任务边说出想法，可揭示策略与知识表征。**经验抽样法**在日常生活的若干时点让参与者报告当时体验。二者依赖可报告内容，不能完整还原全部心理加工，出声报告本身也可能影响任务。

意识有助于选择当前重要信息、限制输入、选择性储存、规划行动和抑制不合适的冲动。人对现实的解释还受到个人经历、需要、信念和文化建构影响。

双任务与视觉搜索研究说明意识资源有限。寻找单一突出特征有时较容易，搜索特征组合通常更需要注意，但表现还取决于刺激怎样组织。

## 三、睡眠与昼夜节律

**昼夜节律**是约24小时的生理活动周期，涉及唤醒、体温、代谢和激素等。**时差**体现内部节律与当地时间线索的失配。24.18小时是特定研究中的平均估计，不能视为所有人的固定周期。

睡眠不是整晚均一的状态。睡眠分为非快速眼动睡眠（NREM）和快速眼动睡眠（REM），不同阶段在夜间交替出现。通常前半夜深睡眠较多，后半夜REM阶段较长。

NREM曾采用阶段1—4的划分。常用的现代划分为N1、N2、N3，旧阶段3、4合并为N3。REM通常伴快速眼动、较活跃的脑电及肌张力下降。[OpenStax：睡眠阶段](https://openstax.org/books/psychology-2e/pages/4-3-stages-of-sleep)。

睡眠参与能量保存、恢复、发育及学习记忆。**REM反弹**指被剥夺后REM睡眠增加的现象。NREM和REM均有重要功能，不能把全部修复或记忆作用只归给一种阶段。

| 睡眠相关问题 | 入门解释 |
| --- | --- |
| 失眠 | 入睡、维持睡眠或睡眠质量持续困难 |
| 发作性睡病 | 清醒状态中出现异常强烈睡意或睡眠发作 |
| 睡眠呼吸暂停 | 睡眠中反复出现呼吸暂停或减少 |
| 梦游 | 睡眠中出现行走等行为，常与NREM睡眠有关 |
| 梦魇 | 令人恐惧且通常可回忆的梦 |
| 夜惊 | 深睡眠中出现强烈惊恐和唤醒，常缺少完整梦境回忆 |

## 四、梦及其他意识状态

梦可以发生于REM和NREM，睡眠研究中REM唤醒后的梦报告较多。

- **显性梦境：**能报告的梦的内容。
- **隐性梦境：**精神分析理论推定的隐藏意义或愿望。
- **激活—整合模型：**脑将睡眠中产生的神经活动整合为梦的体验。
- **清醒梦境：**梦中觉察到自己正在做梦，有时能影响梦的进程。

梦的象征性解释属于特定理论，不能只凭梦境确定真实经历或人格。

**催眠**涉及对暗示的反应及知觉、记忆、控制感的变化，个体的**可催眠性**有差异。**冥想**通过特定注意与练习方式改变意识体验。催眠性痛觉缺失及其相关脑活动是这一领域的研究主题。

## 五、精神促动药物与依赖

精神促动药物通过改变神经活动影响心理和行为。

| 名词 | 解释 |
| --- | --- |
| 耐受性 | 同样剂量的作用减弱，或需要更大剂量才获得类似作用 |
| 生理依赖 | 身体适应后，停用可出现戒断等反应 |
| 心理依赖 | 对相关体验或功能形成持续依赖 |
| 成瘾 | 持续、难以控制的使用，常在不良后果下仍继续 |
| 幻觉 | 缺乏相应外界刺激时出现的知觉体验 |

常见类别包括致幻或知觉改变类、阿片类、镇静类、兴奋类，以及咖啡因和尼古丁。它们作用机制不同，入门分类可能存在交叉。

## 六、复习自测

1. 前意识与无意识加工如何区分？**要点：**可提取但当前未注意，与没有觉察地发生加工。
2. 梦是否只出现在REM？**答案：**不是。
3. 耐受、生理依赖和成瘾是否同义？**答案：**不是，分别强调效应变化、身体适应与失控性使用。
