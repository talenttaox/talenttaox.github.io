# 第十章 人的毕生发展

## 一、背景与发展研究

**发展心理学**研究从受孕贯穿一生的生理和心理变化。发展包含能力获得，也包含某些功能的丧失，个体持续与环境互动。

毕生发展通常划分为胎儿期、婴儿期、童年早期与中期、青少年期、成年早期、中期和晚期。**生理年龄**是出生以来的时间，**发展年龄**是某方面表现对应的典型发展水平。常模描述一般模式，不是要求所有人按同一速度发展的规定。

| 设计 | 做法 | 主要优点与局限 |
| --- | --- | --- |
| 纵向设计 | 长期追踪同一批人 | 可观察个体变化，但成本高、样本流失、外推有限 |
| 横断设计 | 同一时间比较不同年龄群体 | 较快，但年龄差异可能混入出生年代的差异 |

**同辈／出生队列效应**指不同年代的教育与社会经历造成群体差异。**辨析：**纵向设计也受到所处时代影响，不能理解为彻底排除历史条件。

## 二、毕生生理发展

产前发展分为胚种期（最初两周）、胚胎期（约第3—8周）及胎儿期（之后到出生），分别强调植入、器官形成与继续生长。

**致畸物**是可能干扰产前发育的环境因素。相关风险因素包括某些感染、酒精、吸烟及其他物质。**辨析：**风险与因素种类、剂量和发育时点有关，不同暴露并不必然产生相同结果。

新生儿的觅食、吮吸等反射有生存作用。感官、运动和神经系统发展不同步，视崖研究考察深度知觉、运动经验与回避的联系。

青春期出现生长加速及性成熟，脑区发展和社会环境共同影响情绪、决策与风险行为。成年后感觉、生理和生殖功能逐渐变化，变化速度及其影响有明显个体差异。

## 三、皮亚杰认知发展理论

**图式**是组织和理解经验的心理结构。**同化**用已有图式解释新信息，**顺应**修改图式以适应新信息。

| 阶段 | 近似年龄 | 关键特点 |
| --- | --- | --- |
| 感知运动 | 0—2岁 | 通过感觉和动作探索，发展客体永久性及早期符号能力 |
| 前运算 | 2—7岁 | 符号思维增强，常见自我中心和中心化 |
| 具体运算 | 7—11岁 | 守恒、可逆性，对具体事物进行逻辑操作 |
| 形式运算 | 11岁以后 | 抽象及假设性推理 |

**客体永久性**指理解物体即使不在眼前仍然存在，也译作“客体恒常性”。它与第四章的大小、形状等知觉恒常性不同。**自我中心**在此指难以采择他人视角，不等于自私。**中心化**是只关注一个显著维度。**守恒**指外观改变但未增减时数量等属性保持。**可逆性**是理解操作可以反向恢复。

当代婴儿研究提示部分能力可能比经典任务显示的更早。**心理理论**是根据他人信念、愿望等心理状态解释和预测行为的能力。维果斯基强调社会交往、文化工具与内化。阶段理论是理解发展的框架，任务要求和文化经验会影响表现。

## 四、成年认知与语言获得

累积知识与新问题加工可能呈现不同的变化趋势，语义知识可能保持较好，处理速度和部分新学习表现更容易下降，不能把衰老概括为全部认知均匀衰退。

**音素**是语言中具有区别意义作用的最小语音单位。婴儿的语音区分逐渐适应母语。**儿童指向言语**常使用慢语速、高而夸张的语调及简单结构。**快速映射**是从少量接触中初步建立词义联系。**过度规则化**是把学到的语法规则用于例外形式，例如将不规则过去式套用规则词尾。

乔姆斯基强调先天语言准备，实际语言发展也需适当语言环境。先天机制与语言经验如何共同作用，是理解语言发展的重要问题。

## 五、社会性发展

埃里克森强调各阶段的心理社会任务：

| 阶段 | 主要冲突 |
| --- | --- |
| 婴儿期 | 信任与不信任 |
| 学步期 | 自主与羞耻、自我怀疑 |
| 童年早期 | 主动与内疚 |
| 学龄期 | 勤奋与自卑 |
| 青少年期 | 同一性与角色混乱 |
| 成年早期 | 亲密与孤独 |
| 成年中期 | 生成／繁衍与停滞 |
| 成年晚期 | 自我整合与绝望 |

中年的“繁殖”强调对后代、工作和社会的贡献，也常译为生成感，并不只指生育。阶段任务不是一旦失败就永远无法改变的固定命运。

**气质**是反应方式中的早期生物倾向。**依恋**是儿童与照料者间持久的情感联结。鲍尔比的**内部工作模型**说明关系经验如何形成对自己和他人的期待。

安斯沃斯的**陌生情境法**观察分离与重聚：安全型寻求安慰后恢复探索；回避型较少表现接近；矛盾型既寻求接触又难以安抚。不同依恋类型的比例随样本和文化背景而变化。哈洛研究说明接触性安慰有重要作用，不能仅以供食解释依恋。

教养方式按要求／控制与回应／温暖区分：权威型两者较高，专制型高控制低回应，放任型低控制高回应，忽视型两者较低。具体效果仍需考虑儿童特点和文化。

马西亚的同一性状态可以用探索与承诺区分：扩散为两者较少，早闭为缺乏探索但有承诺，延缓为探索中尚未承诺，获得为探索后形成承诺。

成年社会性发展涉及亲密关系、家庭、照料与社会贡献。婚姻满意度的群体变化模式不能直接预测某个人的生活。

## 六、性别、道德与老化

生物性特征、性别相关行为及性别刻板印象需要区分。**辨析：**性别认同是个体对自身性别的认识，不能只用男性化或女性化兴趣高低来定义。群体均值差异也不能决定单个人的能力和选择。

**道德推理**研究判断理由。海因茨两难题主要看“为什么这样选择”，不只看支持或反对偷药。

| 柯尔伯格水平 | 常见阶段与判断依据 |
| --- | --- |
| 前习俗 | 避免惩罚，获取利益与互惠 |
| 习俗 | 获得认可，维持秩序与规则 |
| 后习俗 | 社会契约，普遍伦理原则 |

柯尔伯格的经典模型为三水平六阶段。后续讨论中提出的阶段7属于扩展，不宜混入经典六阶段模型。道德推理与实际行为、文化价值的关系也是评价重点。[OpenStax：毕生发展理论](https://openstax.org/books/psychology-2e/pages/9-2-lifespan-theories)。

**补偿的选择性优化（SOC）**：选择重要目标，在选定领域优化训练，用替代方式补偿丧失。例如减少目标数量、继续练习关键技能，并借助工具完成困难活动。

## 七、复习自测

1. 同化和顺应如何区分？**答案：**用旧图式理解，与修改图式。
2. 为什么横断研究中的年龄差异未必就是发展变化？**答案：**可能存在队列效应。
3. 安全依恋的判断为何要看重聚？**要点：**寻求安慰、恢复探索等调节行为。
4. SOC分别指什么？**答案：**选择、优化、补偿。
