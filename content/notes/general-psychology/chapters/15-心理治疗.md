# 第十五章 心理治疗

## 一、背景与治疗关系

治疗涉及评估问题、形成可能病因解释、估计预后和制订干预。**预后**是对问题发展及改善可能性的判断。

心理治疗通过专业关系及心理方法，帮助改变造成困扰的情绪、思维和行为。心理治疗也涉及情绪体验、关系与功能。[NIMH：心理治疗](https://www.nimh.nih.gov/health/topics/psychotherapies)。

心理治疗由不同专业背景的人员在多种场所提供，各地区的职业资格和培训要求可能不同。

**治疗联盟**包括共同目标、对任务的合作及信任关系。**文化胜任力**要求治疗者意识到自身价值观和偏见，理解来访者背景，并选择适合文化情境的方法。

## 二、心理动力学治疗

心理动力学治疗重视无意识冲突、关系模式和经历之间的联系，传统精神分析常以获得领悟为目标。

| 名词 | 解释 |
| --- | --- |
| 自由联想 | 鼓励自由表达想法与感受，以探索关联 |
| 宣泄 | 表达原本压抑的情感体验 |
| 阻抗 | 治疗过程中对某些内容或改变出现回避与阻碍 |
| 梦的解析 | 在相应理论中探索梦的内容与推定意义 |
| 移情 | 将过去关系中的情感与期待带入治疗关系 |
| 反移情 | 治疗者在关系中产生的情感反应，可能与其自身经验有关 |

后来的心理动力学更重视当前关系、社会环境、自我功能及持续发展。**辨析：**领悟不等于证明某一种历史解释一定真实，对关系反应的理解也需结合实际资料。

## 三、行为治疗

行为治疗使用学习原理改变行为及其维持条件。

| 方法 | 基本思路 |
| --- | --- |
| 反条件作用 | 学习新的反应以对抗不适应反应 |
| 暴露疗法 | 在适当治疗安排下接近引起恐惧的情境，形成新的学习 |
| 系统脱敏 | 传统方法结合放松与逐级接近恐惧情境 |
| 满贯疗法 | 传统暴露方法中直接面对较强恐惧情境 |
| 反应预防 | 接触相关情境时不实施维持问题的仪式或回避反应 |
| 榜样模仿 | 观察并练习适应性行为 |
| 权变／相倚管理 | 按明确的行为—后果关系安排强化 |
| 代币强化 | 用可兑换奖赏的代币支持目标行为 |

厌恶疗法利用刺激配对改变相关反应，属于行为治疗历史中的一种方法，其适用性需结合具体目标和证据判断。

**消退策略**需要识别维持行为的强化物。**泛化技术**帮助治疗环境中获得的行为迁移到日常环境，涉及刺激、强化与练习情境的匹配。

## 四、认知治疗与认知行为治疗

认知治疗关注事件解释、自动思维与信念如何影响情绪和行动。常用思路包括检查基本假设、评估证据、再归因及寻找可行方案。理性—情绪取向强调信念与情绪的关系。

**认知重构**是识别、检验和调整不适应解释。**认知行为治疗CBT**结合认知方法与行为练习。

**例：**“这次答错证明我什么都不会”可以分解为事实（答错一题）、解释（全部能力差）和行动（放弃）。检验证据、形成更准确解释，并练习相关题型，可以同时作用于想法与行为。

CBT重视证据、实际练习及反馈，不能理解为靠积极口号保证结果。

## 五、人本主义与团体方法

**来访者中心疗法**由罗杰斯发展，重视接纳、理解及促进成长。**无条件积极关注**指尊重来访者本身的价值。通常还重视共情及治疗者的真诚。

**格式塔治疗**重视当前觉察和体验整合，空椅技术是其中一种方法。它与第四章用于解释知觉组织的格式塔心理学需区分。

团体治疗提供反馈、观察、人际练习和共同支持。夫妻治疗关注伴侣互动，家庭治疗关注家庭关系系统。社区支持团体可围绕成瘾、疾病、生活变化及亲属压力提供互助，与正式治疗的角色可能不同。

## 六、生物医学治疗

主要药物类别包括抗精神病药、抗抑郁药、心境稳定剂及部分抗焦虑药。一些药物通过影响突触递质的再摄取等环节发挥作用。

**辨析：**药物类别并非与一个诊断机械一一对应，也不能把所有药物理解为单纯“补足某种递质”。药物的作用机制与具体用途需要区分。[NIMH：精神健康药物](https://www.nimh.nih.gov/health/topics/mental-health-medications)。

生物医学治疗的历史涉及前额叶切断术等精神外科方法，相关技术还包括电休克治疗ECT和重复经颅磁刺激rTMS。历史手术与现代脑刺激应放在各自背景中理解。ECT使用电刺激诱发受控发作，rTMS使用磁刺激作用于选定脑区。[NIMH：脑刺激治疗](https://www.nimh.nih.gov/health/topics/brain-stimulation-therapies/brain-stimulation-therapies)。

## 七、疗效评估与预防

**自然缓解**是未经目标治疗而随时间发生的改善。**安慰剂效应**涉及治疗期待等因素。要判断疗效，需要对照、合适的指标及随访，不能只比较治疗前后。

**元分析**用明确规则综合多项研究的结果，其结论仍受纳入研究质量影响。共同因素包括改善期待、可信解释、清楚计划、行为实践及良好治疗关系。共同因素重要，不意味着所有技术对所有问题效果相同。

| 预防层级 | 目标 |
| --- | --- |
| 初级预防 | 问题出现前降低发生风险 |
| 二级预防 | 早期发现，减少持续时间和严重程度 |
| 三级预防 | 限制长期功能影响，预防复发 |

## 八、复习自测

1. 心理动力、行为、认知、人本取向分别关注什么？**答案：**冲突关系、学习后果、解释信念、体验成长。
2. 为什么治疗后好转不必然证明技术有效？**要点：**自然缓解、期待、其他干预与测量变化。
3. 泛化技术解决什么？**答案：**将治疗中的改变维持并迁移到日常生活。
