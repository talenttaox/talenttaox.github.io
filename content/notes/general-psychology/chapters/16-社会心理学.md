# 第十六章 社会心理学

## 一、背景与社会归因

**社会心理学**研究人的思维、情感、知觉、动机和行为如何受到他人、互动及社会情境的影响。

**归因理论**研究人怎样解释行为原因。**内在归因**强调个人倾向，**外在归因**强调环境条件。

| 共变模型信息 | 询问什么 |
| --- | --- |
| 特异性 | 这个人是否只对这一对象或情境这样反应？ |
| 一贯性 | 同一人对同一情境是否反复这样反应？ |
| 共同性／一致性 | 其他人对这一情境是否也如此反应？ |

**例：**一名学生在某课打瞌睡，需了解他是否在所有课都如此、每次该课是否如此，以及其他同学是否也困。不同信息组合支持不同解释。

**基本归因错误**是在解释他人行为时高估个人因素、低估情境。问答游戏研究表明，提问者占据有利角色，仍可能被认为更有才学。**自我服务偏差**是把成功更多归于自己、失败更多归于环境。

**自我实现预言**指期望改变了对他人的行为，后者作出相应反应，使原期望得到支持。教师期待研究说明这种互动路径，但特定研究中的效应不能成为对任何学生的保证。

## 二、角色、规范与从众

**社会角色**是某位置对应的行为期待，**规则**是具体情境的行为指南，**社会规范**是群体对适当行为的共同期待。

斯坦福监狱实验是讨论角色和情境力量的历史研究。**方法辨析：**研究需要考虑研究者介入、参与者对要求的理解及伦理，不能据单一研究推出所有人会被角色完全支配。[原始材料的档案检验研究：Debunking the Stanford Prison Experiment](https://doi.org/10.1037/amp0000401)。

**从众**是采纳群体意见或行为的倾向。

| 影响 | 动机 | 经典实验 |
| --- | --- | --- |
| 信息性影响 | 希望判断正确，参考他人信息 | 谢里夫的自主运动效应 |
| 规范性影响 | 希望得到接纳、避免排斥 | 阿施的线段判断 |

**自主运动效应**是在黑暗无参照条件下，静止光点看似运动的错觉。群体成员的判断逐渐汇聚，独处时可能仍保留已形成的规范。

阿施研究使用明确线段判断和多数同伙的错误答案，考察参与者是否随众。不同指标需要区分，例如“至少从众一次”的人数比例与全部关键试次中的从众率不是同一数值。

少数派即使缺乏较强规范压力，也可能因一致表达和提供不同信息促进思考。

## 三、群体决策与服从

**群体极化**是讨论后向群体原有倾向的更极端方向移动，可由信息积累和社会比较解释。**群体思维**是为了保持一致而抑制异议、忽略不利证据的决策模式。

**服从**是遵循权威要求，米尔格拉姆研究考察了这一现象。其背景包括被认为有权威的实验者、逐步升级的要求及责任解释。服从、从众和顺从相关但不同：分别强调权威命令、群体影响和具体请求。

## 四、态度、说服与行为

**态度**是对人、物或观念的评价，涉及认知、情感和行为信息。态度的稳定性、可获得性及测量方式影响其预测行为的程度。

**精细加工可能性模型ELM**区分两种说服路径：中心路径仔细分析论据，外周路径更多依赖表面线索。是否愿意、是否有能力加工信息，会影响走哪条路径。

**认知失调**是行为、信念等不一致时产生的不适及改变动机。人可能改变行为、调整态度或寻找辩解。**自我知觉理论**强调人通过观察自己的行为和情境推断态度，二者的解释重点不同。

**顺从**是回应他人的请求。

- **互惠规范：**接受帮助后感到应当回报。
- **以退为进／门面技巧：**先提大请求，被拒后提较小请求。
- **登门槛技巧：**先得到小请求的同意，再提较大请求。

## 五、偏见与减少偏见

| 名词 | 区分重点 |
| --- | --- |
| 刻板印象 | 对群体成员的概括性信念，认知层面 |
| 偏见 | 对群体的评价与情感倾向 |
| 歧视 | 对群体成员的不公平行为，概念区分 |
| 内群体／外群体 | 自己认同的群体与其他群体 |
| 内群体偏向 | 更偏袒自己群体的倾向 |
| 刻板印象威胁 | 担心自己的表现证实群体负面印象的压力 |
| 行为确证 | 期待影响互动，从而引出符合期待的行为 |

**内隐偏见**指自动出现的评价联系。**内隐联想测验IAT**通过分类反应时间研究联结。**辨析：**一次结果不能充分概括个人的所有态度与实际行为。

**接触假设**强调恰当群际接触可能减少偏见。仅仅碰面未必足够，共同目标、合作和关系形成很重要。

## 六、人际吸引与爱

喜欢受到外表评价、相似性和互惠等因素影响，其中外表标准具有文化特点，信念和价值相似常促进交往。

爱的不同成分可用**激情、亲密、承诺**描述，成人依恋则涉及安全、回避、焦虑矛盾等倾向。成人关系模式不是由童年单向固定，后续经历和当下关系也会影响表现。

## 七、攻击与亲社会行为

**攻击**涉及意图伤害他人的行为。**冲动性攻击**由强烈情绪驱动，**工具性攻击**把伤害作为达到目标的手段。影响攻击的因素包括挫折、挑衅、规范及榜样，**挫折—攻击假说**中的关联不能解释为一切挫折必然造成攻击。

**亲社会行为**以帮助他人为方向，**利他动机**强调他人的利益。帮助动机可以区分为利他、利己、集体和原则等类型，外表相同的行为可能有不同动机。

**互惠性利他**涉及帮助与未来回报的关系，**间接互惠**涉及更广的社会回报链。**同理心—利他假说**认为对他人处境的情感理解可引发帮助动机。

**旁观者效应**关注他人在场时个体介入的变化。**责任分散**使人认为其他人会负责。介入通常需要先注意到事件、再感到责任。**例：**明确指出某人承担具体任务，可减少“大家都以为别人会做”的问题。人数效应还取决于事件是否清楚、是否危险等情境。

## 八、复习自测

1. 从众、顺从、服从有何区别？**答案：**群体意见、具体请求、权威要求。
2. 群体极化与群体思维有何区别？**答案：**倾向更加极端，与压制异议追求一致。
3. 刻板印象、偏见、歧视如何对应？**答案：**信念、评价情感、行为。
4. 为什么“群体人数更多”不必然“帮助更多”？**要点：**责任分散及事件解释。
