# 第四章 感觉和知觉

## 一、背景与基本框架

知觉包括获取、组织、辨认环境信息并赋予意义。可以区分三个阶段：**感觉**将刺激转换为神经信号，**知觉组织**整合感官证据和已有知识形成表征，**辨认与识别**确定客体是什么以及它有什么意义。

**远距刺激**是环境中的客体，**近距刺激**是它在感受器上形成的刺激模式，如视网膜成像。知觉任务是由近距刺激推断外部客体。**换能**是把光、机械振动等刺激能量转换成可被神经系统处理的细胞信号。

## 二、心理物理学与阈限

| 名词 | 定义或要点 |
| --- | --- |
| 心理物理学 | 研究物理刺激与心理体验、行为之间的关系 |
| 绝对阈限 | 在指定条件下，约50%试次能被检测到的刺激强度 |
| 差别阈限／最小可觉差 | 约50%试次能察觉两个刺激差异的最小差值 |
| 心理测量函数 | 刺激强度与检测比例之间的函数 |
| 感觉适应 | 对持续刺激的反应逐渐减弱 |
| 反应偏差 | 刺激感觉性质之外的因素造成的回答倾向 |
| 信号检测论 | 将感受性与决策标准区分开来分析检测表现 |

**韦伯定律：**在适用范围内，最小可觉差与基准刺激强度之比近似恒定，即 `ΔI / I = k`。**例：**越重的物体，通常需增加更多重量才容易察觉变化，这是一种比例关系。

信号有无与回答有无可以组合成击中、漏报、虚报、正确拒绝。害怕漏报的人可能更容易报告“有”，但这种策略变化不代表感受性必然提高。

## 三、视觉系统

瞳孔调节进光量，晶状体参与聚焦并通过调节改变厚度，视网膜上的光感受器将光信号转为细胞信号。

| 结构 | 关键功能 |
| --- | --- |
| 杆体细胞 | 适于低照度环境，与暗适应有关 |
| 锥体细胞 | 参与颜色及精细视觉，明亮条件下作用突出 |
| 中央凹 | 锥体细胞密集，精细辨别能力较高 |
| 双极细胞与神经节细胞 | 参与纵向信息传递，神经节细胞轴突组成视神经 |
| 水平细胞与无长突细胞 | 参与视网膜横向加工 |
| 盲点 | 视神经离开视网膜处缺少光感受器 |

视觉分析涉及模式识别与位置加工等通路。**失认症**指感觉基本功能可能保留，却难以辨认相应对象的障碍。**感受野**是某细胞对刺激作出反应所对应的视野区域。简单、复杂等视觉细胞对方向、运动、长度等特征具有选择性。

颜色体验的维度是**色调、饱和度、明度**。光的加法混合与颜料等的减法混合机制不同。

- **三原色理论：**三类锥体系统的相对活动参与颜色编码。
- **拮抗加工理论：**后续加工存在红—绿、蓝—黄等对立通道，可解释部分后像现象。

两种理论可以说明不同加工阶段。三类锥体通常按短、中、长波长敏感性区分，其敏感范围彼此重叠。

## 四、听觉与其他感觉

声波**频率**主要对应音高，**振幅**与响度相关，复合波成分与音色相关。听觉经历声音传导、耳蜗中机械振动、毛细胞换能和神经通路加工。

**地点说**强调基底膜不同位置的活动，**频率说**强调活动时间模式。不同理论的解释范围存在重叠，不宜用互不重叠的频率边界划分。两耳时间差和强度差参与声音定位。

- **嗅觉：**参与食物识别、危险探测等。信息素在部分动物的交流中发挥作用，其作用不能直接推及人类。
- **味觉：**甜、酸、苦、咸、鲜五种基本味道。食物风味还大量依靠嗅觉。
- **肤觉：**包括压力、温度等，身体各部位的敏感性不同。
- **前庭觉：**提供头部运动及相对重力方向的信息，感受器位于内耳。
- **动觉：**提供肌肉、肌腱、关节的运动与位置反馈。
- **痛觉：**与伤害性刺激相关，是防御信号，也受中枢加工、注意和情境影响。

**门控理论**强调脊髓及下行影响对疼痛信号的调节。**神经矩阵论**强调脑网络参与疼痛体验，帮助理解缺乏明显外周刺激时的疼痛。疼痛体验与外周组织损伤并非简单一一对应。

## 五、知觉组织

注意可以由当前目标引导，也可以被突出的刺激捕获。图形—背景分离使某部分被识别为前景。格式塔组织原则包括：接近、相似、连续、闭合、共同命运。

**边界扩展**指记忆中的场景边界可能超过原图范围。**变化盲视**指人未能察觉场景中的变化。**Φ现象**说明在合适时空条件下，静止刺激的交替也能产生运动体验。

| 深度线索 | 内容 |
| --- | --- |
| 双眼线索 | 视网膜像差、视轴辐合 |
| 运动线索 | 观察者运动时产生的运动视差 |
| 单眼线索 | 遮挡、相对大小、线条透视、质地梯度 |

**知觉恒常性**是在感受器输入变化时仍较稳定地知觉物体，主要包括大小、形状、亮度恒常性。**错觉**是对实际刺激的系统性错误解释，可揭示正常知觉的组织规则。

## 六、辨认、情境与定势

**自下而上加工**由刺激特征驱动。**自上而下加工**依赖知识、经验、目标和期望。音素重建、两可图形等体现两种加工的相互作用。

**定势**是暂时的准备状态。运动定势侧重预设动作，心理定势侧重习得规则或解题方式，知觉定势侧重期待看到某种刺激。

## 七、复习自测

1. 感觉与知觉有何区别？**要点：**信号获取与组织、解释。
2. 绝对阈限和差别阈限各判断什么？**答案：**有无刺激与是否有差异。
3. 走近物体时视网膜像变大，为何仍觉得物体一样大？**答案：**大小恒常性，依赖深度等线索。
4. 同一两可图为何能有不同解释？**要点：**输入不充分确定意义，情境与期望参与解释。
