# 第七章 记忆

## 一、背景：记忆是多种过程和系统

**记忆**是编码、存储和提取信息的能力。**编码**将信息加工为表征，**存储**使信息随时间保持，**提取**使已有信息重新被使用。想不起来可能与任何环节有关，不能一律认定为存储内容消失。

| 分类 | 含义 | 例子 |
| --- | --- | --- |
| 外显记忆 | 有意识地记起或报告过去信息 | 回忆上节课内容 |
| 内隐记忆 | 过去经验影响表现，无需有意识回忆 | 启动效应 |
| 陈述性记忆 | 关于事实和事件 | 概念知识、经历 |
| 程序性记忆 | 关于怎样做事情 | 骑车、熟练打字 |
| 情景记忆 | 个人经历的具体事件 | 某次生日 |
| 语义记忆 | 不依赖特定时空事件的概念知识 | 词义、公式 |

外显／内隐关注记忆的使用方式，陈述性／程序性关注内容与系统，这两套分类不应机械地完全等同。**生成汇编**说明练习可使操作程序自动化，也可能造成熟练动作中的自动性错误。

## 二、感觉记忆、短时记忆与工作记忆

**感觉记忆**短暂保留感官输入。**映像记忆**是视觉感觉记忆。斯佩林的部分报告法用短暂呈现后的线索指导报告其中一行，揭示视觉输入的瞬时保持能力较大但衰退迅速。

**短时记忆**暂时维持少量信息。米勒提出 `7±2` 的容量估计，考恩在更严格条件下提出约3—5个项目的估计，容量取决于任务、材料及是否允许组块等条件。

**复述**维持当前材料。**组块**将项目重新组织为有意义单位，例如把数字串按熟悉年份分组。组块借助长时知识提升可保持的信息量。

**工作记忆**除暂时保持外，还支持操作信息和协调任务。

| 巴德利模型成分 | 功能 |
| --- | --- |
| 语音环路 | 暂时保持和处理言语信息 |
| 视觉空间画板 | 暂时保持和处理视觉、空间信息 |
| 中央执行系统 | 分配注意并协调各成分 |
| 情景缓冲区 | 容量有限，整合来自不同来源的信息 |

例如，边记电影时间边寻找纸笔，既需要“保持”信息，也需要执行搜索等“操作”。运算广度测验可研究工作记忆的个体差异。

## 三、长时记忆的编码和提取

**提取线索**是搜索目标记忆时可利用的信息。回忆要求生成答案，再认要求判断眼前项目是否经历过，后者通常提供更直接的线索。

- **编码特异性：**提取线索与编码时的信息相匹配，有助于提取。
- **背景依赖性：**环境背景匹配可能帮助回忆。
- **状态依赖性：**编码与提取的内部状态匹配可能影响表现。状态匹配效应是实验研究中的现象，不意味着改变身体状态就是合适的学习方法。
- **系列位置效应：**序列开头、结尾通常比中间更容易记住，分别称首因、近因效应。
- **时间区辨性：**项目在时间上凸显于其他项目的程度。
- **加工水平：**意义等较深加工通常有利于记忆。
- **迁移适宜性加工：**编码时的加工与测验所需加工匹配，有利于表现。
- **启动效应：**先前接触影响后来对相同或相关信息的加工。

“深加工”与“匹配”不是同一个原则。复习既要理解含义，也要练习考试要求的提取方式。

## 四、遗忘、记忆术与元记忆

艾宾浩斯用无意义音节和重学的**节省成绩**量化遗忘。遗忘曲线常体现早期遗忘较快、后来减缓，其形状受材料和学习条件影响。

| 干扰 | 方向 | 例子 |
| --- | --- | --- |
| 前摄干扰 | 旧信息干扰新信息 | 老密码干扰记住新密码 |
| 倒摄干扰 | 新信息干扰旧信息 | 新号码干扰回忆旧号码 |

**精细复述**通过解释、联系和意象丰富编码。**地点法**把项目与熟悉地点依序联系，**桩词法**把项目与固定线索联系。

**元记忆**是对自身记忆的认识与监控。**知道感**是暂时不能回忆时对能否再认的判断，**学习判断**是对自己学得如何的估计。熟悉感与真正能独立回忆需区分。

## 五、长时记忆的组织与重构

**概念**是类别的心理表征，常形成层级。**基础水平**是适合日常分类的中间层次。**图式**是关于对象、人或情境的概括知识框架，**脚本**说明事件通常怎样依序展开。**原型**代表类别的典型特点，**范例**是记忆中的具体成员。

回忆具有重构性，个体会使用图式及后来信息补充、组织过去。巴特利特的“幽灵的战争”研究展示：趋平化简化内容，精细化突出细节，同化使内容更符合已有文化知识。

**错误信息效应**是事后信息影响对原事件的回忆。车祸用词实验和“迪斯尼里的兔八哥”案例说明暗示可以影响记忆报告。共同目击者的讨论也可能污染回忆。

**闪光灯记忆**具有生动感和较高主观确信，但生动程度不保证准确性。记忆可能非常自信而仍有错误。

## 六、记忆的生物学

拉什利的早期迷宫研究强调分布式加工，但复杂任务涉及多个系统，不能据此认定全部记忆均匀存于整个皮层。

海马参与新陈述性及空间记忆的形成与巩固，杏仁核参与情绪记忆，纹状体与习惯和刺激—反应学习有关，小脑参与部分技能和条件学习，皮层参与分布式表征。

**顺行性遗忘**指损伤后难以形成新的相关记忆，**逆行性遗忘**指损伤前的记忆丧失。外显受损时部分内隐或程序性学习仍可保留，支持多记忆系统观点。

## 七、复习自测

1. 工作记忆比短时保持多了什么？**答案：**加工和协调功能。
2. 背出新密码时总说成旧密码是哪种干扰？**答案：**前摄干扰。
3. 为什么目击者的确信不能直接证明准确？**要点：**重构、事后信息与主观评价可能分离。
4. **学习应用：**用概念组织、精细解释和主动回忆检查学习，避免只凭重复阅读的熟悉感判断掌握程度。
