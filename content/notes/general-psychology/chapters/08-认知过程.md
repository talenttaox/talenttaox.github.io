# 第八章 认知过程

## 一、背景与研究认知

**认知**涵盖各种“知”的形式，包括知识内容以及操作这些内容的过程。概念、事实、命题、规则和记忆属于内容，理解、推理、解决问题等属于过程。

唐德斯研究说明：任务新增心理步骤可能增加反应时间，因此可以借行为指标推断内部加工。

| 概念 | 定义 |
| --- | --- |
| 反应时 | 完成指定反应或任务所需时间 |
| 序列过程 | 多个加工步骤依次进行 |
| 平行过程 | 多个加工同时进行 |
| 受控过程 | 需要注意资源，通常难与另一受控任务同时进行 |
| 自动过程 | 经练习后较少需要有意识控制的加工 |

反应时推断依赖任务和模型假设，不能直接把一个时间差当作唯一心理步骤的证据。熟练动作在陌生或困难情境中也可能重新需要控制。

## 二、语言生成与理解

**听众设计**指表达时考虑听众及双方共享知识。共同基础可以来自团体身份、此前共同活动或谈话，以及共享的知觉事件。

格赖斯合作原则包括：信息量适当，尽量真实，与当前话题相关，表达清楚有序。它们描述合作交流的原则，具体语境中还会出现暗示、反语等使用方式。

**口误**可以揭示词汇选择、句法安排和语音计划。**斯本内现象**是词语首音互换。SLIP技术通过先呈现特定词对来诱发这类口误，说明错误有规律，不能把所有口误都理解为隐藏欲望。

语言理解要处理词义歧义和结构歧义，语境能帮助选择解释。**命题**是意义表征的基本单位。人们常记得意思，难以逐词保留原句。**推论**利用已有知识填补文本未明说的信息。

语言的生成性使有限词汇能表达大量新意义。动物符号学习与完整的人类语法能力需区分。**语言相对论**认为语言结构会影响思考方式。**辨析：**“影响思维”不意味着语言完全决定思维，研究结果取决于任务与文化背景。

## 三、视觉认知

**视觉表象**是客体不在眼前时的内部视觉表征。心理旋转研究考察人在头脑中转动物体表征的过程。真实知觉与想象在部分活动和处理特点上重叠，但二者不完全相同。

语言可以帮助形成空间心理模型，例如根据描述想象房间和物体位置。表象也有局限，不能仅靠直觉可靠处理极大数量或指数增长。

**辨析：**计算纸张对折50次后的理想厚度，需要先确定纸张初始厚度。若初始厚度为 `t`，理想数学模型为 `t×2^50`，它不是现实中能够完成的折纸过程。

## 四、问题解决与创造性

**问题空间**由初始状态、目标状态及允许的操作构成。定义良好的问题有清楚规则和目标，定义不良的问题首先需要明确问题是什么。

| 概念 | 解释 |
| --- | --- |
| 算法 | 在适用条件下，按明确程序可得到正确解答的方法 |
| 启发式 | 经验性策略，可节省资源但不保证正确 |
| 功能固着 | 只按熟悉用途看待物品，阻碍发现新用途 |
| 创造性 | 在情境中产生新颖且适宜的思想或产品 |
| 发散思维 | 产生多种可能的方案，体现流畅性和灵活性 |
| 聚合思维 | 整合信息，寻找合适解答 |
| 顿悟 | 突然获得问题解决办法的体验 |

练习基础成分、形成合适的问题表征，可以减少资源负担。出声思维报告可用于研究解题策略。

## 五、演绎与归纳推理

**演绎推理**在前提成立并正确运用逻辑规则时得到必然结论。**归纳推理**根据已有证据提出可能结论，可能被新证据修正。**类比推理**利用先前情境与新情境的对应关系解决问题。

**信念偏差**是按结论是否可信判断推理是否有效。**例：**“所有A都是B，某物是B，所以它是A”无效，因为还可能有其他B。

沃森选择任务中，检验“元音背面是偶数”，应翻 **A与7**。A用于寻找元音背面为奇数的反例，7用于检查奇数背面是否为元音。D和4不能直接检验该规则的反例。

**心理定势**是沿用已有方法的倾向，在相似问题中有益，在结构变化后可能妨碍解题。

## 六、判断、启发式与决策

判断是形成评价和结论，决策是在备选方案间选择。

| 机制 | 核心问题 | 常见风险 |
| --- | --- | --- |
| 可得性启发式 | 哪些例子容易想起？ | 以记忆容易程度替代真实频率 |
| 代表性启发式 | 像不像某类典型成员？ | 忽视基率等信息 |
| 锚定启发式 | 从起始数值向上或向下调整 | 调整不足，受无关起点影响 |
| 峰—尾规则 | 根据高峰与结尾概括体验 | 总时长及其他阶段可能被低估 |
| 框架效应 | 同一结果怎样描述？ | 等价的收益与损失说法影响选择 |

决策研究还区分**知足者**与**最大化者**：前者倾向选择达到要求的方案，后者努力寻找最优方案。选择范围、错失机会和结果反馈会影响后悔及后续风险行为。

## 七、复习自测

1. 算法和启发式的保证程度有何不同？**要点：**适用条件下可靠程序与不保证正确的捷径。
2. 代表性与可得性如何区分？**答案：**典型程度与容易想起程度。
3. 如何评价一个演绎论证？**要点：**分别检查前提真实性与逻辑有效性。
