# 第九章 智力与智力测验

## 一、背景：测量的意义

**心理测量／心理评估**用特定程序评估能力、行为与个人特征。它通常研究个体差异，即某人在指定维度上与其他人的相似和差异。

科举及高尔顿的工作是理解测量历史的不同例子。高尔顿强调个体差异可以量化，能力可以客观测试，测验之间的关联可以统计分析。测验的发展也伴随关于公平、文化和误用的争论。

## 二、测验质量：信度、效度、标准化

| 术语 | 定义或辨析 |
| --- | --- |
| 信度 | 分数的一致性与可靠性 |
| 重测信度 | 同一群体不同时间的测量结果一致程度 |
| 内部一致性 | 测验各项目或部分之间的一致程度 |
| 内容效度 | 测验内容是否恰当覆盖所要测量的领域 |
| 效标关联效度 | 分数与相关外部标准的联系 |
| 构念效度／结构效度 | 证据是否支持用分数解释目标心理构念 |
| 标准化 | 统一施测、计分与解释程序 |
| 常模 | 用适当参照群体的分数分布解释个体结果 |

**辨析：**奇偶项目分半是内部一致性的一种检验思路，并不只看两部分均值是否相等。效度不能只概括为与外部标准的相关，构念效度涉及多类证据。稳定的测验未必测对了目标。

## 三、智力测验的起源与IQ

**智力**涵盖推理、计划、解决问题、抽象思维、理解复杂思想及从经验学习等能力。1905年的比奈—西蒙测验用于识别需要教育支持的儿童，心理年龄用于比较儿童的表现水平。

斯坦福—比奈量表对测验进行修订和标准化。比率智商公式为：

`IQ = 心理年龄 / 生理年龄 × 100`

上述是历史上的比率IQ。现代常见IQ采用同年龄常模中的相对位置表示，常以均值100、标准差15计分。不能用成人“心理年龄”简单套历史公式。

韦克斯勒测验家族包含成人、儿童与学前儿童的测验。具体版本、年龄范围和常模应以使用工具的正式手册为准。

理解低分范围、高能力表现及教育支持需求时，需结合适应行为和发展背景。分数是评估资料之一，不能把一个IQ数字当作个人价值或全部能力。

**辨析：**“天才”在教育研究中可以是多维构念，不同定义可能结合能力、创造力与任务投入。智商与学业差距不能被机械地当成所有学习障碍的统一判据。

## 四、主要智力理论

| 理论 | 主要内容 |
| --- | --- |
| 斯皮尔曼二因素观点 | 一般因素g参与多类认知任务，特殊因素s对应特定任务 |
| 卡特尔的流体与晶体智力 | 流体智力重视新问题与关系推理，晶体智力重视累积知识技能 |
| 斯滕伯格三因素理论 | 分析智力、创造智力、实践智力 |
| 加德纳多元智力理论 | 语言、逻辑数学、空间、音乐、身体运动、人际、内省、自然观察等能力 |
| 情绪智力 | 知觉和表达情绪、利用情绪促进思维、理解情绪、调节情绪 |

**因素分析**是从多个测量之间的关联提取潜在维度的统计方法。它是心理测量学探索能力结构的重要方法。

扩展智力概念有助于关注多样能力，但各理论的定义和证据基础并不完全相同。多元智力不能直接转换成“每个人只有一种固定学习方式”。

## 五、遗传、环境、文化与公平

双生子研究用于估计群体中的遗传力，环境中的教育、资源、营养与经验同样影响表现。需要注意：**组内遗传力不能解释组间差异**，更不能据此断定某族群的先天能力。

对遗传力随年龄变化的一种解释涉及个体逐渐选择或塑造与自身倾向相合的环境。具体估计范围依赖样本和条件，不是普遍常数。

文化背景影响题目熟悉度、语言理解及测验意义。**刻板印象威胁**是担心表现证实所属群体负面印象的情境压力，这种压力可能影响注意、表现监控及心理资源。

测量与社会的伦理重点包括决策公平、教育评价的用途，以及分类对个人机会的影响。测验解释必须说明常模是否合适、测量是否可靠，以及分数适用于什么目的。

## 六、重点名词与复习自测

**流体智力：**解决新异问题和识别关系的能力。**晶体智力：**累积的知识和技能。**g因素：**多类认知任务共享的一般因素。**常模：**分数解释的参照标准。

1. IQ100意味着什么？**要点：**相对于适当常模接近平均位置，不能解释为全部能力的绝对尺度。
2. 为什么高信度不保证效度？**要点：**一致性与测量目标的准确性不同。
3. 高遗传力是否排除教育影响？**答案：**不排除。
4. 为什么跨文化比较要谨慎？**要点：**题目内容、语言、教育机会及测量等价性。
