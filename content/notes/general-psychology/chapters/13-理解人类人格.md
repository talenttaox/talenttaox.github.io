# 第十三章 理解人类人格

## 一、背景：人格与特质

**人格**是一组对个体特征性行为模式有跨时间和情境影响的心理品质。人格理论试图说明结构、起源及其如何与行为相联系。

**特质**是较持久的倾向或描述维度。奥尔波特区分首要特质（可能支配生活）、核心特质（主要特点）和次要特质（较局部的偏好）。卡特尔提出16因素，艾森克提出外向性、神经质、精神质三个维度。**辨析：**这里的“精神质”是历史特质模型的术语，不能直接用作精神病诊断。

| 大五维度 | 主要关注 |
| --- | --- |
| 外倾性 | 社交活跃、积极情绪及外向表达 |
| 宜人性 | 合作、信任、体贴 |
| 尽责性 | 组织、自律、责任与坚持 |
| 神经质 | 负性情绪与情绪不稳定倾向，反向是稳定性 |
| 开放性 | 新经验、想象与思想探索 |

各维度是连续分布，不能把人固定分成五类。特质可受遗传影响，也可随经验发展。

**一致性悖论**是人格评定较一致，但单次行为跨情境的一致性较低。“如果……就……”模式可以解释人如何对不同情境作出有规律的不同反应。特质理论擅长描述差异，但仅有描述不足以解释形成机制。

## 二、心理动力学与精神分析

弗洛伊德强调驱力、无意识冲突及早期经验。**力比多**在其理论中指与性及寻求满足有关的心理能量。其心理性欲发展包括口唇、肛门、性器、潜伏、生殖阶段，**固着**用于解释某阶段冲突持续影响后来人格。

这些属于历史理论，不应把阶段主张、俄狄浦斯情结或特定童年事件与人格的联系当作所有人的既定规律。

| 人格结构 | 理论中的主要原则 |
| --- | --- |
| 本我 | 驱力与即时满足，快乐原则 |
| 自我 | 协调现实条件、欲望和规范，现实原则 |
| 超我 | 内化的道德要求与理想 |

**精神决定论**强调心理行为有其心理原因。**防御机制**是缓解冲突和焦虑的心理策略，可能无意识地改变对经验的理解。

| 防御机制 | 含义 |
| --- | --- |
| 压抑 | 将难以接受的内容排除在意识之外 |
| 否认 | 拒绝承认难以接受的现实 |
| 转移／置换 | 将情绪转向较安全的对象 |
| 投射 | 将自身难以接受的倾向归于他人 |
| 合理化 | 为行为提供可接受理由以减少不适 |
| 反向形成 | 用相反态度掩盖难以接受的冲动 |
| 退行 | 在压力下出现较早期、较幼稚的反应方式 |
| 升华 | 将冲动导向社会认可的活动 |
| 认同 | 通过与重要人物或群体相认同影响自我 |
| 隔离 | 将体验与相关情感分开 |
| 幻想 | 通过想象获得愿望满足 |

**辨析：**从单次行为难以可靠判断具体防御机制，不能见到“生气后运动”就直接确定其无意识原因。

对精神分析理论的主要批评包括概念操作化困难、预测能力不足、回溯解释、文化和男性中心偏见。后继理论中，阿德勒强调克服自卑，霍妮强调关系与文化，荣格强调集体无意识和原型。它们并非已被统一验证的同一套结论。

## 三、人本主义

**自我概念**是关于自身特征、价值和行为的心理模型。**自我实现**是发展个人潜能的过程。罗杰斯强调**无条件积极关注**及自我与经验的关系。

接纳一个人的价值可以与对具体行为提出界限同时存在。人本主义重视整体经验、成长、个体视角和当前生活，但部分概念不易明确测量。

## 四、社会学习与认知理论

- **罗特：**行为倾向与奖赏期望、奖赏价值相关。**控制点**指结果被归于自身行为还是外部力量的倾向，分别称内控、外控。
- **米希尔：**编码方式、期望信念、情感、目标价值、能力和自我调节计划共同影响情境中的行为。
- **班杜拉：**交互决定论强调个人因素、行为和环境相互影响，观察学习支持个体从他人获得信息。

**自我效能感**是相信自己能在特定情境完成任务。**结果期望**是相信某行为会带来某结果。**例：**相信练习有效属于结果期望，相信自己能坚持练习并掌握属于效能信念，两者可以不同。

## 五、自我理论与文化

詹姆士区分物质我、社会我、精神我。**自我图式**组织关于自己的信息。**自尊**是对自身的总体评价，与具体任务的效能信念不同。

**自我提升**维护积极自我评价。**自我妨碍**是为可能失败预先提供借口，例如不充分准备后把成绩归于没努力。**恐惧管理理论**讨论死亡意识、文化世界观与自尊之间的关系。

自我研究区分**独立自我构念**与**互依自我构念**，可用二十句测验观察自我描述。**辨析：**这是文化倾向的比较，不能把每个文化成员都视为相同，也不能忽略生物和个人经历。

## 六、人格测评

**客观测验**采用统一施测与计分规则，常包括自陈问卷。MMPI系列用于临床相关评估，NEO系列基于大五结构。不同版本的测验具有相应常模，解释结果需考虑正式常模和用途。

**投射测验**用模糊刺激引发解释或故事，例如罗夏墨迹测验、主题统觉测验。某些用途与推论的效度证据不足，不能仅凭一个故事或图形反应确定人格。

## 七、理论对照与自测

特质理论重在描述维度，心理动力学重在冲突与无意识，人本主义重在成长体验，社会认知理论重在学习、解释与情境，自我理论重在自我信息及文化建构。

1. 特质是否能保证一次行为？**答案：**不能，情境和其他因素共同影响。
2. 自尊与自我效能感有何区别？**答案：**总体价值评价与具体任务能力信念。
3. 为什么人格测评要查信度、效度和常模？**要点：**一致性、用途解释与参照群体适配。
