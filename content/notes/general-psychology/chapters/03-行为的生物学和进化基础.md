# 第三章 行为的生物学和进化基础

## 一、背景：遗传、环境与进化

解释行为既要考虑遗传，也要考虑环境。**基因型**是个体的遗传构成，**表型**是可观察的形态或功能表现，表型受到基因及环境共同影响。

**自然选择**指可遗传差异在特定环境中影响生存和繁殖，相关特征的频率因此在后代中改变。地雀案例中，干旱改变食物来源，适合啄食硬种子的喙形提高了繁殖成功率。这里的“适应”指相对于特定环境的适合程度。

人类进化中的两足化释放了手并改变活动方式，大脑化支持复杂推理和计划，语言又促进文化传递。

**行为遗传学**通过双生子、收养等研究分析遗传与行为差异。**遗传力**是特定群体和环境下，个体间某特征变异可归于遗传差异的比例。它不能解释一个人的某特征“有百分之多少由基因造成”，也不代表该特征无法改变。

## 二、神经元及信息传递

| 结构或概念 | 主要作用 |
| --- | --- |
| 树突 | 接收其他神经元或感受器的输入 |
| 胞体 | 维持细胞生命并参与信息整合 |
| 轴突 | 将神经信号传向末端 |
| 终扣 | 轴突末端结构，参与释放神经递质 |
| 髓鞘 | 包裹部分轴突，提高传导效率 |
| 郎飞氏节 | 髓鞘间隙，与有髓轴突传导有关 |
| 突触 | 神经元之间或神经元与效应细胞之间的信息传递部位 |

**动作电位**是达到阈值后产生并沿轴突传播的快速膜电位变化。**全或无定律**表示单次动作电位在阈值以上通常不会随刺激增强而变得更大。**不应期**是一次动作电位后暂时不能或较难再次产生动作电位的时期。

动作电位的基本过程是钠离子内流参与去极化，钠通道失活、钾离子外流参与复极化，离子泵维持长期浓度梯度。刺激强弱可以通过放电频率和参与神经元数量等编码。[OpenStax：神经系统细胞](https://openstax.org/books/psychology-2e/pages/3-2-cells-of-the-nervous-system)。

化学突触传递中，递质释放进入突触间隙，与突触后受体结合，影响下一细胞活动。主要神经递质包括乙酰胆碱、GABA、谷氨酸、多巴胺、去甲肾上腺素、5-羟色胺及内啡肽。

GABA通常发挥抑制性作用，谷氨酸是重要兴奋性递质；乙酰胆碱参与肌肉活动及认知，多巴胺涉及运动和奖赏学习，内啡肽参与疼痛调节。递质功能取决于受体、脑区及神经网络，不能把一种递质简单等同于一种情绪。

## 三、研究大脑的方法

损伤研究观察脑区受损后的功能变化，盖奇病例、布洛卡的研究及动物损伤实验都是典型例子。经颅磁刺激可暂时干预部分脑区活动。

| 方法 | 入门理解 |
| --- | --- |
| EEG，脑电图 | 记录头皮电活动，适合观察活动随时间的变化 |
| CT，计算机断层扫描 | 检查脑结构 |
| MRI，磁共振成像 | 提供脑结构影像 |
| PET，正电子发射断层扫描 | 通过示踪技术观察代谢等活动 |
| fMRI，功能磁共振成像 | 通过血氧相关信号间接反映功能活动 |

脑成像发现某区域更活跃，并不单独证明该区域是某行为的唯一原因。

## 四、神经系统与脑结构

神经系统分为**中枢神经系统**（脑和脊髓）与**外周神经系统**。外周系统包括躯体系统及自主系统。交感系统常参与动员身体应对挑战，副交感系统常参与恢复和日常维持，二者共同调节内部状态。

| 结构 | 主要功能 |
| --- | --- |
| 脑干及网状结构 | 基本生命活动、警觉水平 |
| 丘脑 | 多种感觉信息的中继 |
| 小脑 | 运动协调 |
| 海马 | 新记忆获得和巩固，H.M.案例是重要证据 |
| 杏仁核 | 情绪加工及情绪记忆 |
| 下丘脑 | 进食、饮水、体温及内稳态 |
| 额叶 | 运动、计划及控制等功能 |
| 顶叶 | 躯体感觉及空间加工等功能 |
| 颞叶 | 听觉及语言相关加工 |
| 枕叶 | 视觉加工 |

脑功能常依赖多个区域共同参与，表格用于建立初步结构地图。

## 五、偏侧化、内分泌与可塑性

**半球功能偏侧化**指某些功能在两半球的参与程度有差异。裂脑研究通过切断胼胝体后的表现研究信息交流。左、右视野的信息主要到达对侧半球，不能误记为“左眼只连右脑、右眼只连左脑”。正常人的半球持续合作。

主要内分泌器官包括脑垂体、甲状腺、甲状旁腺、肾上腺、胰腺和性腺。**内分泌系统**通过激素经血液影响靶组织，与神经系统一起调节身体。

神经可塑性指神经系统随经验或损伤改变结构、功能的能力。它使经验能够影响神经系统的连接与加工方式。

## 六、复习自测

1. 为什么高遗传力不等于不可改变？**要点：**遗传力描述群体差异，依赖环境，不能替代个体发展解释。
2. 单次动作电位如何遵循全或无定律？**要点：**达阈值则产生，强刺激通常不增大单次幅度。
3. 海马、杏仁核、下丘脑的功能如何区分？**要点：**记忆、情绪、内部状态调节。
